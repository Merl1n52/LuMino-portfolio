# LUMINO DESIGN STUDIO — WordPress Theme & Portfolio Site

Минималистичная премиум-тема для WordPress, воссоздающая дизайн и архитектуру шаблона **Operator Framer** с адаптивными карточками работ.

## Особенности
1. **Шапка сайта**:
   - Название: **LUMINO DESIGN STUDIO**
   - Индикатор статуса: зелёная пульсирующая точка + `Available for work`
   - Живые студийные часы с секундами и городом
   - Кнопка «Get in Touch» и мобильное меню-шторка
2. **Адаптивные карточки работ (Works)**:
   - Базовый стандартный размер: **552 × 690** (`aspect-ratio: 552 / 690`).
   - Автоматическая адаптивность: если вы вставляете картинку с нестандартными пропорциями (например, 552×685, 552×688 или баннер), карточка плавно адаптируется под её размер без обрезки и искажений.
   - Микро-анимация плавного зума при наведении (`transform: scale(1.035)` с `cubic-bezier`).
3. **Типографика и цвета**:
   - Шрифты Google Fonts: **Big Shoulders Display** (для монументальных цифр счетчиков 23, 04, 25), **Inter Tight**, **Inter**.
   - Фирменные цвета: глубокий черный `#121212`, чистый фон `#f9f9f9`, рамки `#e5e5e5`.
4. **Секции главной страницы**:
   - Hero со счетчиками статистики (`+Projects`, `+Years`, `+Clients`) и манифестом/био
   - Recent Works (сетка карточек в 2 колонки)
   - Services (`[01]`, `[02]`, `[03]`)
   - Archive Work (сетка архивных работ)
   - Footer с гигантской кликабельной почтой с анимацией подчеркивания и кнопкой «Back to Top»
5. **Внутренние страницы**:
   - `single-portfolio.php` / `single-project.html`: Страница кейса с мета-информацией (Год, Услуга, Клиент, Роль) и поддержкой длинных скролл-макетов (например, `BRUTAR.png`).
   - `archive-portfolio.php` / `works.html`: Каталог всех работ.
   - `page-about.php` / `about.html`: Страница о студии с фото профиля (`me.jpg`) и таймлайном опыта (2019 — настоящее время).
   - `404.php`: Фирменная страница ошибки 404.

## Как использовать

### 1. Быстрый просмотр без сервера
Вы можете прямо сейчас дважды кликнуть по любому HTML-файлу в папке `LuMino Site` и открыть его в Google Chrome или Microsoft Edge:
- `index.html` — Главная страница
- `works.html` — Каталог всех проектов
- `about.html` — Страница «О студии»
- `single-project.html` — Пример кейса с макетом презентации

### 2. Установка темы в WordPress
1. Откройте админ-панель WordPress (`wp-admin`).
2. Перейдите в **Внешний вид -> Темы -> Добавить тему -> Загрузить тему**.
3. Выберите готовый архив `lumino-theme.zip` из папки `LuMino Site`.
4. Нажмите **Установить** и затем **Активировать**.

### 3. Настройка темы в WordPress
- **Внешний вид -> Настроить (Customizer)**:
  - Название студии (по умолчанию: `LUMINO DESIGN STUDIO`)
  - Статус (по умолчанию: `Available for work`)
  - Локация / Город для часов (по умолчанию: `Curitiba, Brazil` или укажите свой город)
  - Таймзона для часов (например, `Europe/Chisinau` или оставьте пустым для локального времени)
  - Счетчики проектов, лет и клиентов
  - Email для связи и социальные сети
- **Добавление работ (Портфолио)**:
  - В меню появится раздел **Портфолио** (Works)
  - Нажмите «Добавить новую работу», укажите заголовок, установите «Изображение записи» (Featured Image)
  - В блоке под редактором укажите **Год**, **Услугу/Дисциплину**, **Клиента** и выберите режим карточки: **Standard 552x690** или **Adaptive**.
